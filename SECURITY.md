# Security Policy

This repository is an open-source satellite / example application built on the
[Suwappu API](https://github.com/0xSoftBoi/suwappubot). Suwappu is non-custodial
by design — it never holds your keys or your funds.

## Reporting a vulnerability

**Do not open a public issue for security reports.** Instead:

- Use **GitHub Private Vulnerability Reporting** on this repository
  (Security → Report a vulnerability), or
- Email **layerinfinite@gmail.com**
  _(replace with security@suwappu.bot once that alias is live)_.

Please include the affected file, version or commit, reproduction steps, and an
impact assessment. Encrypted reports welcome.

**Scope note:** issues in *this* repository's own code (the example app, its SDK
usage, dependencies, or CI) belong here. Vulnerabilities in the **Suwappu API,
core bot, smart contracts, or key-management layer** should be reported upstream
via the core repository's
[security advisories](https://github.com/0xSoftBoi/suwappubot/security/advisories/new).

## Our commitment

- **Acknowledge** within 3 business days.
- **Triage & severity** within 7 business days (CVSS-based).
- **Coordinated disclosure:** we agree a timeline with you and credit you in the
  release notes unless you prefer to remain anonymous.

## Safe harbor

Good-faith research conducted under this policy — without privacy violation, data
destruction, or service degradation — will not result in legal action from us.
If in doubt, ask first.
